# Geometric_lib

## 1. Общее описание решения

Проект представляет собой библиотеку на Python для вычисления площади и периметра геометрических фигур.

В библиотеке реализованы две фигуры: круг и квадрат.

Структура проекта:

- `circle.py` — функции для работы с кругом и окружностью.
- `square.py` — функции для работы с квадратом.
- `tests/test_circle.py` — автоматические тесты функций круга.
- `tests/test_square.py` — автоматические тесты функций квадрата.

Для проверки корректности работы библиотеки используется встроенный модуль Python `unittest`.

## 2. Описание функций

### 2.1. Модуль circle.py

Модуль содержит две функции для работы с кругом и окружностью.

**Функция `area(r)`**

Вычисляет площадь круга по формуле:

\[
S = \pi r^2
\]

Параметр:
- `r` — радиус круга (целое или вещественное число).

Пример использования:

```python
import circle

print(circle.area(2))
```

Результат:

```text
12.566370614359172
```

**Функция `perimeter(r)`**

Вычисляет длину окружности по формуле:

\[
P = 2\pi r
\]

Параметр:
- `r` — радиус круга (целое или вещественное число).

Пример использования:

```python
import circle

print(circle.perimeter(2))
```

Результат:

```text
12.566370614359172
```

### 2.2. Модуль square.py

Модуль содержит две функции для работы с квадратом.

**Функция `area(a)`**

Вычисляет площадь квадрата по формуле:

\[
S = a^2
\]

Параметр:
- `a` — длина стороны квадрата (целое или вещественное число).

Пример использования:

```python
import square

print(square.area(5))
```

Результат:

```text
25
```

**Функция `perimeter(a)`**

Вычисляет периметр квадрата по формуле:

\[
P = 4a
\]

Параметр:
- `a` — длина стороны квадрата (целое или вещественное число).

Пример использования:

```python
import square

print(square.perimeter(5))
```

Результат:

```text
20
```

## 3. Требования к входным данным

Все функции библиотеки принимают целые (`int`) и вещественные (`float`) числа.

Допустимые значения:
- ноль;
- положительные конечные числа.

Некорректные значения обрабатываются следующим образом:

| Входные данные | Поведение |
|---|---|
| Отрицательное число | `ValueError` |
| `NaN` | `ValueError` |
| `inf` | `ValueError` |
| `-inf` | `ValueError` |
| Строка (`str`) | `TypeError` |
| Логическое значение (`bool`) | `TypeError` |
| `None` | `TypeError` |
| Список (`list`) | `TypeError` |
| Кортеж (`tuple`) | `TypeError` |
| Комплексное число (`complex`) | `TypeError` |

Для проверки корректности входных данных используются вспомогательные функции `_validate_radius(r)` и `_validate_side(a)`.

`TypeError` возникает, если передан неподдерживаемый тип данных.

`ValueError` возникает, если передано числовое значение, которое не может использоваться в вычислениях: отрицательное, бесконечное или `NaN`.

## 4. Тестирование

Для проверки библиотеки используется модуль `unittest`, входящий в стандартную библиотеку Python.

Автоматические тесты находятся в папке `tests`:

- `test_circle.py` — тестирование функций `area(r)` и `perimeter(r)` из модуля `circle.py`.
- `test_square.py` — тестирование функций `area(a)` и `perimeter(a)` из модуля `square.py`.

Тесты проверяют:
- корректность вычислений;
- работу с целыми и вещественными числами;
- обработку нулевых значений;
- обработку отрицательных чисел;
- обработку неподдерживаемых типов данных;
- обработку `NaN` и бесконечностей;
- работу с очень маленькими и большими значениями.

Для запуска всех тестов из корневой папки проекта необходимо выполнить команду:

```powershell
py -m unittest discover -s tests -v
```

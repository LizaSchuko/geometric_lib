# Geometric_lib

### 1. Общее описание решения
Проект состоит из двух файлов:
* `circle.py` — для окружности и круга.
* `square.py` — для квадрата.

Файл `circle.py` содержит две функции:
* `area(r)` — для вычисления площади круга.
* `perimeter(r)` — для вычисления длины окружности.

Файл `square.py` содержит две функции:
* `area(a)` — для вычисления площади квадрата.
* `perimeter(a)` — для вычисления периметра квадрата.

---

### 2. Описание каждой функции с примерами вызовов

####  Файл `circle.py`

##### Функция `area(r)`
Принимает радиус круга, возвращает площадь этого круга (произведение числа Пи на квадрат радиуса).

* **Пример вызова в коде:**
```python
res = circle.area(2)
print(res)  # Выведет: 12.566370614359172
```

##### Функция `perimeter(r)`
Принимает радиус круга, возвращает длину окружности этого круга (произведение числа Пи на удвоенный радиус).

* **Пример вызова в коде:**
```python
res = circle.perimeter(2)
print(res)  # Выведет: 12.566370614359172
```

####  Файл `square.py`

##### Функция `area(a)`
Принимает сторону квадрата, возвращает площадь этого квадрата (возводит длину стороны в квадрат).

* **Пример вызова в коде:**
```python
res = square.area(2)
print(res)  # Выведет: 4
```

##### Функция `perimeter(a)`
Принимает сторону квадрата, возвращает периметр этого квадрата (сумму четырех одинаковых сторон).

* **Пример вызова в коде:**
```python
res = square.perimeter(2)
print(res)  # Выведет: 8
```

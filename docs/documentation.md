# Geometric_lib

### 1. Общее описание решения

Проект представляет собой библиотеку для вычисления площади и периметра геометрических фигур.

Проект состоит из двух файлов:

* `circle.py` — функции для работы с кругом и окружностью.
* `square.py` — функции для работы с квадратом.

Файл `circle.py` содержит две функции:
* `area(r)` — вычисление площади круга.
* `perimeter(r)` — вычисление длины окружности.

Файл `square.py` содержит две функции:
* `area(a)` — вычисление площади квадрата.
* `perimeter(a)` — вычисление периметра квадрата.

### 2. Описание функций с примерами вызовов

#### Файл `circle.py`

##### Функция `area(r)`

Вычисляет площадь круга по заданному радиусу.

* **Входные параметры:**
  * `r` — радиус круга (`int` или `float`), неотрицательное конечное число.

* **Возвращаемое значение:**
  * `float` — площадь круга.

* **Формула:**

  `S = π * r²`

* **Пример вызова:**

```python
res = circle.area(2)
print(res)  # 12.566370614359172
```

##### Функция `perimeter(r)`

Вычисляет длину окружности по заданному радиусу.

* **Входные параметры:**
  * `r` — радиус круга (`int` или `float`), неотрицательное конечное число.

* **Возвращаемое значение:**
  * `float` — длина окружности.

* **Формула:**

  `P = 2 * π * r`

* **Пример вызова:**

```python
res = circle.perimeter(2)
print(res)  # 12.566370614359172
```

---

#### Файл `square.py`

##### Функция `area(a)`

Вычисляет площадь квадрата по заданной длине стороны.

* **Входные параметры:**
  * `a` — длина стороны квадрата (`int` или `float`), неотрицательное конечное число.

* **Возвращаемое значение:**
  * `int` или `float` — площадь квадрата.

* **Формула:**

  `S = a²`

* **Пример вызова:**

```python
res = square.area(2)
print(res)  # 4
```

##### Функция `perimeter(a)`

Вычисляет периметр квадрата по заданной длине стороны.

* **Входные параметры:**
  * `a` — длина стороны квадрата (`int` или `float`), неотрицательное конечное число.

* **Возвращаемое значение:**
  * `int` или `float` — периметр квадрата.

* **Формула:**

  `P = 4 * a`

* **Пример вызова:**

```python
res = square.perimeter(2)
print(res)  # 8
```

### 3. Требования к входным данным и обработка ошибок

Все четыре функции принимают один аргумент — радиус круга или длину стороны квадрата.

Допустимые типы данных:
* `int` — целое число.
* `float` — вещественное число.

**Допустимые значения:**
* Ноль.
* Положительные целые числа.
* Положительные конечные вещественные числа.

**Недопустимые значения:**

| Входное значение | Ожидаемое поведение |
| :--- | :--- |
| Отрицательное число | `ValueError` |
| `NaN` (не число) | `ValueError` |
| `inf` (положительная бесконечность) | `ValueError` |
| `-inf` (отрицательная бесконечность) | `ValueError` |
| Строка (`str`) | `TypeError` |
| Логическое значение (`bool`) | `TypeError` |
| `None` | `TypeError` |
| Список (`list`) | `TypeError` |
| Кортеж (`tuple`) | `TypeError` |
| Комплексное число (`complex`) | `TypeError` |

**Обработка ошибок:**

* `TypeError` возникает, если передан аргумент неподдерживаемого типа.
* `ValueError` возникает, если передано число допустимого типа, но недопустимого значения: отрицательное число, `NaN` или бесконечность.

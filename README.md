# Geometric_lib

Библиотека на Python для вычисления площади и периметра геометрических фигур.

Подробная документация: [docs/documentation.md](docs/documentation.md)

## Реализованные фигуры

### Круг

- Площадь: \(S = \pi r^2\)
- Длина окружности: \(P = 2\pi r\)

### Квадрат

- Площадь: \(S = a^2\)
- Периметр: \(P = 4a\)

## Структура проекта

- `circle.py` — функции для работы с кругом.
- `square.py` — функции для работы с квадратом.
- `tests/` — автоматические тесты библиотеки.
